# Pure Control app releases

Release files for the Pure Control desktop app by [Pure BPM](https://www.purebpm.com): the signed Mac app, the Windows installer, and the update files the app reads.

Installed copies of Pure Control check the published releases here and update themselves. Releases are drafted by the app's release workflow and published by hand. Only plain version numbers (for example `v0.2.0`) are ever installed.

The app's source is private. For help, contact Pure BPM through [purebpm.com](https://www.purebpm.com).
